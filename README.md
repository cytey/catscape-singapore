# Catscape Singapore

I want to create an app called catscape for singapore. So this app is meant to be like a superapp for cats, has a few features. The site must use all the cat vocabulary 

1) allow me to raise fund so that I can care for my cats and also the community cats

2) store to sell products which I can populate via backend

3) post updates on the fund amount and how much has been used for caring for the needy cats

4) news or events on cats in Singapore

5) guides on caring for cats or hacks

6) a online dictionary of all the cat vocabulary 

7) a generator to allow visitors to generate outputs based on cat vocabulary for input text

8) allow users to create a cat, upload picture, says it's location and update feeding status and any status or comments for the cat

9) show all the cat boarding foster services, pet taxi

10) show all the vets services and cat whisperers

suggest more which will make this app a superapp
